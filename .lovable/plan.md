# Publish Relay for iPhone and check the + button

The iPhone version is already built: home-screen icon, full-screen launch, bottom tab bar, the + quick-capture button and the install guide. What's left is to put it live and test it.

## Steps
1. Run a security check, then publish to https://carterhub.carterlab.app.
2. On the live site, confirm the app details file and the 180px Relay icon load, so iPhone shows the real icon and opens Relay full screen.
3. In a signed-in iPhone-sized browser, tap +, save a test idea ("Test idea from + button"), then open Ideas and confirm it's listed. Afterwards, delete the test idea, or keep it if you'd rather.
4. Fix anything that fails, then publish again.

## What only you can do
Adding Relay to your Home Screen has to be done on your own iPhone: open the site in Safari, tap Share, then Add to Home Screen. I'll walk you through it and tell you what to check.

## Not included
- A native App Store app (you chose the Home Screen version earlier).
- Offline use, which is left out so you never see an old version.
